# Release 0.7.3 — Generic Welcome and Accession Review

Dashboard and Member Home now share: “Explore the library catalog and access the services available to you.”

Accession uniqueness was verified in the source: BookRequest applies a table-level unique rule (ignoring only the edited book), XLSX imports reuse it and reject duplicate accession values within a workbook, and the original catalog migration creates a database UNIQUE index. Archived books retain their accession numbers. No new schema change is necessary.

Added regression coverage for editing another book to an existing/archived accession, direct database insertion bypassing validation, and existing/archived accession imports with atomic rollback. Suite now has 82 tests. These PHP tests could not be executed here because native PHP is unavailable. Source and patch scope checks passed; this is not confirmation of the user's live database schema or a passing native suite.

Extract over v0.7.2, then run:

```bat
php artisan optimize:clear
php artisan test
```

No migration or asset rebuild is required. README and existing migrations remain unchanged.
