# 0.14.3 — Pending requests on the dashboard

16 November 2026. Apply over v0.14.2 and run `php artisan optimize:clear`.

- The dashboard shows separate cards for pending book issue requests and pending member registrations below the welcome message.
- Each card appears only when it has a positive count and the user can access the linked queue. The book issue card opens Issue Requests with the Pending filter applied.
