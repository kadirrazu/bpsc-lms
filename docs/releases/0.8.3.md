# Release 0.8.3 — Request Filter Alignment

Search and Issue Status labels/fields now align at the top of their row. The search hint no longer pushes the shorter status column downward. Buttons have a responsive label spacer to align with the inputs, and retain their side-by-side spacing.

Extract over v0.8.2 and run `php artisan optimize:clear`. No migration or asset rebuild is required.

Validation: scoped form markup, balanced containers and existing utility styles checked. Native PHP/browser execution is unavailable here; no full-suite or browser pass is claimed.
