# Release 0.6.0 — Catalog Views and Member Registration

Baseline: v0.5.0. Stable root README and existing migrations are unchanged.

## Changes

- Thumbnail/list toggle on Books, member catalog and contributor book lists. Filters and 20-book pagination preserve view mode.
- Exact Match, Starts with and Partial Match for accession/call number. Partial matches any position and treats `%`/`_` literally; it can scan more rows than an indexed exact lookup.
- Public member registration linked below Sign In, with all seven requested fields and confirmation. Pending applicants cannot sign in. Administrator/Librarian review and approve from Dashboard/Users/Administration; approval always creates Library Member, never a submitted privileged role.
- Optional 11-digit mobile after Role in backend user create/edit; mandatory in public registration. String storage preserves leading zeroes.
- Member book issue requests and private request/loan lists. Staff, Librarian and Administrator can approve/reject requests, issue one available copy, and mark a request-originated loan returned. Stock and duplicate checks run under locks; issue/return logs and lifetime issue counts remain integrated.
- Separate hashed pending credentials are removed after approval. Registration/approval/request review events are audited. No automatic email/SMS notification is configured.

## Apply

Back up project/database, extract this root-relative Paste & Replace ZIP over v0.5.0, then run:

```bat
php artisan optimize:clear
php artisan migrate --force
php artisan test
```

No npm/Composer update or asset rebuild is needed. Existing `.env`, database, users, roles and catalog data are preserved. Migration adds mobile and the registration/request tables. See `docs/member-registration.md` and `docs/catalog.md`.

## Verification and limits

- Production Vite build passed; PHP source and Blade expression static parsing passed.
- Browser fixtures for registration and book list passed at 390, 768 and 1440 px without document overflow or script errors. Mobile input retained its leading zero and accepted 11 digits/rejected letters. Fixtures do not run Laravel or database authorization.
- Eleven new regression tests cover registration, approval permissions, credential/role safety, mobile validation, partial matching, view selection, request ownership, stock, issue/return and repeat review. Suite now contains 67 tests.
- Native PHP is unavailable here: `php artisan test` cannot start (`php: command not found`). Full PHPUnit results, migrations and authenticated Laravel flows are unverified; no all-tests-passed claim is made.
- Partial matching has no new speed guarantee. Existing v0.5.0 SQL-only benchmark does not establish end-to-end/MySQL partial-search timing.
