# Release 0.6.1 — Registration Layout and Password Guidance

Baseline: v0.6.0. Stable root README, database and migrations are unchanged.

## Changes

- Users has an icon-labelled Member Registration Requests button with pending count. The Administration registration link has the same person-plus icon.
- Sign In links to “Join as a Library Member”. Registration retains the same shared software/commission heading as Sign In and adds a short English explanation of existing accounts, manual approval and remembering sign-in credentials.
- Authentication layout uses a growing main region and a non-shrinking footer. Long registration forms scroll naturally, avoiding the previous full-height page/footer conflict.
- Login and registration fields use two columns from tablet/desktop widths and one column on mobile. Password/confirmation are paired on registration.
- Registration password guidance updates 300 ms after typing stops or immediately on blur: missing requirements in red, satisfied requirements in green. Confirmation gets matching/mismatching feedback. Both password fields have accessible show/hide toggles; existing remasking on submit/page hiding is retained. Server validation remains authoritative; login does not impose registration-strength rules on an existing password.

## Apply

Extract this root-relative Paste & Replace ZIP over v0.6.0 and run:

```bat
php artisan optimize:clear
php artisan test
```

No migration, dependency install or frontend rebuild is required. Compiled CSS/JS and manifest are included.
