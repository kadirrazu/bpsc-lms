# 0.13.0 — Library Reports

11 November 2026. Apply this Paste & Replace patch over the 8 November LMS reference ZIP (v0.12.1).

- The signed-in header displays the name in bold with the designation below it in regular text.
- `php artisan library:create-admin` uses the same numeric Designation and Department menus as CMO. Autocomplete is disabled for these two prompts to avoid Symfony's Unix terminal cleanup in Windows CMD. The development-only environment check still applies.
- Administrator and Librarian can open Reports, filter the results and download the full filtered report as PDF or Excel. Report views and downloads record audit events. The Issue Management shortcut is labelled Flagged Issues.

| Report | Contents and filters |
| --- | --- |
| Daily Issue & Return | Issues, returns and copy counts by day. Defaults to today and supports an inclusive date range. Returns use their own return date. |
| Book Acquisitions | Titles added, recorded copies, price per copy, known value and titles without price. Filter by date and collection method. Includes archived books. |
| Member Directory | Member contact details, designation, unit, account date, status and current copies on loan. Filter by account creation dates and status. |
| Category Inventory | Title and copy counts by category, with a distinct catalog total. Select a category for its book list. |
| Open & Overdue Loans | Current loans, due times and fine flags. Filter to overdue or fine-flagged open loans. |
| Most Issued Books | Ranking by issue transactions in a date range, with copy counts. |
| Annual Summary | Calendar-year monthly and annual totals for circulation, acquisitions and member accounts added. Includes all 12 months. |

Date filters follow the application's Dhaka time zone. Acquisition value uses the current recorded unit price multiplied by the current recorded copy count, including for archived titles. Unpriced titles contribute no amount. A title can appear in more than one category. The distinct inventory total counts each title once.

PDF uses the included Nikosh font for Bengali text and repeats table headers on later pages. Excel preserves leading zeros in accession numbers and stores text as text.

After applying the ZIP, run `php artisan optimize:clear` and `php artisan test`. The patch requires no database migration or frontend build.

Full test suite passed with 146 tests and 5,522 assertions on PHP 8.4.27 with SQLite. The suite covers report permissions, date boundaries, inventory overlap, member and overdue filters, and PDF/Excel downloads. A three-page acquisition PDF with Bengali titles was also rendered and inspected. Windows CMD and MySQL were outside this test environment.
