# 0.11.2 — Issue Request Book Details

Date: 5 November 2026. Applies over v0.11.1.

The Issue Requests Book column now displays accession number, mandatory Bengali book title and all authors on separate lines. Accession uses muted slate, title uses the theme primary blue, and authors use teal. Only the title is bold. Missing details have a neutral fallback. Authors are eager loaded with the paginated requests, avoiding per-row author queries. Existing source/status badges remain unchanged.

Extract the root-relative patch into the existing project and run:

```sh
php artisan optimize:clear
php artisan test
```

No migration or frontend build is required. Stable README and existing database files remain unchanged.

Validation: source checks verified the three-line order, title-only bold styling, eager loading, existing badges, available color utilities, and ZIP integrity. PHP/runtime and Composer dependencies are unavailable here, so the Laravel suite and browser rendering were not verified. Full-suite success is not claimed.
