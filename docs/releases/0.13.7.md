# 0.13.7 — Current loans on Member Home

12 November 2026. Apply over v0.13.6 and run `php artisan optimize:clear`.

- Library Members can see their current loans on Member Home. Each row displays the book, accession number, copy count and due date. Available catalog records link to the book details page.
- Copies on Loan on the individual book page is explicitly restricted to Administrator, Librarian and Library Staff. Borrower names are queried only for those roles.
