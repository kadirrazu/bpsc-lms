# Release 0.4.0 — Book Catalog, Multi-Select Metadata and Activity

Baseline: v0.3.0 Profile Access and Branding update.

## Added

- Book, Author, Publisher and Category CRUD with clean English interfaces and Bengali primary titles/names. English titles/names are optional and searchable.
- Books top menu plus one combined Catalog Setup menu for Authors, Publishers and Categories.
- Multiple authors and categories per book, at least one of each required; a single required publisher. Remote search pickers support Bengali/English lookup, chips, removal and keyboard selection.
- Unique text accession number, free-text call number, optional shelf/year, positive copies defaulting to 1, and optional cover image upload/preview.
- Live catalog/master search, bounded lookup results and pagination. Catalog filters match any linked author/category. Member Catalog now lists real books and details; issue requests are still a later phase.
- Cover replacement/removal/deletion cleanup, including durable retry for filesystem failures. No public storage link is required.
- Outstanding-issue deletion guard and stock-reduction guard. Soft-deleted books retain accession identity/history; their cover files are removed.
- Book Add/Edit activity plus Issue/Return events and lifetime Total Times Issued. One issue record counts as one issuance regardless of quantity; returns and edits do not increase the counter. The circulation data/model foundation is present; issuing, returns and approval screens are not part of this release.
- Book Activity timeline for Administrator/Librarian, with a link to all subject-filtered audit logs.
- Indigo/teal product title text and locally bundled Noto Sans Bengali. Root README is unchanged.

## Apply

Back up the project/database. Extract this Paste & Replace ZIP over the existing v0.3.0 project, then run:

```bat
php artisan optimize:clear
php artisan migrate --force
php artisan test
```

Compiled frontend assets and fonts are included. No Composer/npm dependency update or seeding is required. Start by adding Authors, Publishers and Categories under Catalog Setup, then add Books.

Successful cover operations clean old files immediately. For any failed deletion after correcting filesystem permissions, run:

```bat
php artisan library:purge-cover-files
```

The same retry runs every minute through Laravel's scheduler. For local automatic scheduling use `php artisan schedule:work`; production should invoke `php artisan schedule:run` every minute.

See `docs/catalog.md` for schema, lifecycle, counter semantics and future circulation integration.
