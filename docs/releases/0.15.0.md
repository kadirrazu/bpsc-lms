# 0.15.0 — Membership numbers, library cards and issue receipts

17 November 2026. Apply over v0.14.3. Back up the database, run `php artisan optimize:clear`, then run `php artisan migrate`.

- Member accounts receive a six-digit number when added by staff, approved after self-registration, or converted to Library Member. The first two digits are the year in Bangladesh time. The last four digits increment from 0001 within that year's prefix. Existing Library Member records, including inactive and soft-deleted members, are numbered in original account creation order for each year. Deactivation or deletion does not release a number. Each year prefix supports 9,999 numbers.
- Member Home and My Profile offer an 85.60 × 53.98 mm membership card with the member's name, designation, unit, number and a QR code containing that number. Administrator and Librarian can also download a card from the member's user edit page. The issue desk member lookup and Users search accept membership numbers.
- Account email validation treats case variants as the same address, including emails belonging to soft-deleted accounts. The database's existing unique email constraint remains in effect.
- Successful issues offer an optional PDF receipt. All books issued in the same operation share one receipt. It has a Member copy and a Library copy with handwritten signature space on both. The Library copy adds return acceptance signature and date fields. The issue date, member details, titles, accession numbers and quantities are recorded at issue time. Staff can reprint from Issue Requests or Issue Register. Pre-upgrade loans can print a single-loan receipt using their existing loan records.
