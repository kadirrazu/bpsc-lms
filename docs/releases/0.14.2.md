# 0.14.2 — Accession picker and issue book columns

16 November 2026. Apply over v0.14.1 and run `php artisan optimize:clear`.

- The available-copy picker combines browsing, searching and selecting in one field. The same picker is used for direct issue and request approval.
- Find a book displays the book title and authors. Exact accession searches still preselect the matching available copy.
- Issue Register and Issue Requests share the Book heading and cell layout. Cells show the accession, linked title and authors on separate lines. Issued records display saved loan snapshots. Archived titles appear as text.
