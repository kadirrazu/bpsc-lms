# Release 0.2.1 — Shared Layout Syntax Fix

Baseline: v0.2.0. The supplied test report recorded 4 failures and 13 passes (105 assertions). All four failures reported the same ParseError in `resources/views/layouts/app.blade.php`.

## Fix

Removed doubled namespace separators from the shared layout selection expression. This restores valid compiled PHP when administration pages or member profile/password pages use the shared layout. Authentication, role permissions and database behavior are unchanged.

Added one regression test that compiles every Blade view through Laravel's Blade compiler and validates the resulting PHP with `token_get_all(..., TOKEN_PARSE)`. The test reports the template filename if compilation produces invalid PHP.

## Apply

Extract this Paste & Replace ZIP over the existing v0.2.0 project, then run:

```bat
php artisan view:clear
php artisan test
```

No migration, seeding, dependency installation or frontend build is required. The fixed root README is unchanged.

## Validation

The original doubled-separator expression was reproduced as a PHP parse failure with php-parser; the corrected expression and updated PHP test/config sources parse successfully. View expression checks are performed during preparation. Native PHP/Composer are unavailable here, so the Laravel test suite has not been rerun in this environment; the included regression test uses the actual Laravel compiler when run locally.
