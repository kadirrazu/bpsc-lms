# 0.15.3 — Issue Register and Issue Requests recovery

17 November 2026. This Paste & Replace patch includes the v0.15.2 receipt update, with fixes for both circulation pages. Apply over v0.15.1 or v0.15.2.

Run `php artisan optimize:clear` after replacing the files to reload routes and Blade views. If the v0.15.2 migration has already run, there is no new migration. Otherwise, run `php artisan migrate` to install the return-receiver fields.

The v0.15.2 ZIP omitted `routes/web.php`, so it did not install the new Return Receipt route. This ZIP includes that file.

Issue Register and Issue Requests continue to display records when the route cache predates a receipt route. Receipt buttons appear when their routes are registered. The two pages no longer depend on a separate receipt-links Blade view.
