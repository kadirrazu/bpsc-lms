# Release 0.8.2 — Issue Request Filters

Baseline: v0.8.1.

Management Issue Requests now has a shared text search and status filter, with Search/Clear buttons. Status options are Pending, Approved (all), On loan, Returned, Rejected and Withdrawn. Approved includes all approved requests; On loan/Returned additionally filter the linked loan's actual return timestamp.

Search matches Bengali/English book titles, accession/call numbers, member name, designation, unit code/display name, email and mobile. Literal `%` and `_` do not act as wildcards. Archived book/member history remains searchable through the existing relationships. Status and search conditions are combined, and numbered 20-row pagination retains them. Authorization remains unchanged.

Extract this root-relative patch over v0.8.1 and run:

```bat
php artisan optimize:clear
php artisan test
```

No migration, dependency install or asset rebuild is required. README and existing migrations are unchanged.

Source/scope checks covered grouped search conditions, status/loan mapping, input validation, query-string pagination, form labels and existing responsive utility classes. Four regression tests were added for status semantics, search fields, combined conditions, archived/literal matches, pagination, validation and role access. Suite totals 92 tests.

Native PHP is unavailable here (`php: command not found`), so the full suite and native database execution could not run. No passing PHPUnit or browser result is claimed.
