# 0.16.2 — Reuse accession numbers after book deletion

26 November 2026. Apply over the 24 November 2026 reference project (v0.16.1), then run:

```bash
php artisan optimize:clear
php artisan migrate
```

Deleting a book releases its primary and additional copy accession numbers for reuse. The migration also releases numbers belonging to books deleted before this update. Add Book, Edit Book, and Excel import follow the same rule.

Database constraints continue to enforce unique reserved accession numbers. Archived book records, copy records, loan links, and receipt snapshots retain their original values and identities. A replacement book has its own ID and issue history.

Books with open loans must have every copy returned before deletion. Restoring an archived book checks that its accession numbers are available before reserving them again.

Delete Book now opens a confirmation dialog. Type uppercase `DELETE` exactly, with no spaces, to enable the final delete button. The server validates the same exact value. Cancelling or closing the dialog clears the confirmation text.
