# Release 0.5.0 — Dashboard, Clouds and Search Performance

Baseline: v0.4.0 Catalog update.

## Changes

- Idempotent default categories: `অন্যান্য / Others` and `ক্যাটাগরী নির্দিষ্ট করা হয়নি / Uncategorized`. Existing category data is preserved; no automatic reassignment of books.
- Author/Publisher/Category BN and EN text fields now have the same explicit 48 px height. Book bilingual title fields use the same sizing.
- Compact full-width dashboard welcome card, four information cards (book records, copies, currently issued copies, users/member count), latest five added books and latest five issue records.
- Top-24 category and author clouds show active-book counts and drill down into linked book lists. Names on the master pages and book details/cards also open contributor lists.
- Catalog and contributor book lists paginate at 20 records. Contributor scope cannot be overridden through query parameters.
- Dedicated accession/call fields with Exact or Starts with matching and supporting composite indexes. General bilingual/related-name substring search remains available.
- Set-based metadata ID lookups replace per-book nested metadata/name scans. Only 20 result models and relationships are hydrated; bounded page/count caches avoid repeated work and repeated counts on subsequent pages. Revision-based invalidation handles CRUD, pivot edits and dashboard changes.
- Dashboard/statistics and clouds have separate cache invalidation from issue/user changes; catalog stock is hydrated fresh on every request. Live-search debounce reduced to 180 ms, with cancellation of superseded requests.
- Read-only `library:benchmark-catalog` command for measuring actual local database queries. Synthetic SQL evidence/reproduction script is in `docs/benchmarks/`.
- Added 13 regression tests; complete suite contains 56 tests. Stable root README and existing migrations are unchanged.

## Apply

Back up the project/database, extract this Paste & Replace ZIP over v0.4.0, then run:

```bat
php artisan optimize:clear
php artisan migrate --force
php artisan test
```

No Composer/npm update, frontend rebuild or separate seeding command is required. Compiled assets are included. `CategorySeeder` is also included in DatabaseSeeder for new installations.

Latest Issues uses existing issue records; it will show an empty state until circulation records exist. Member login still opens the separate member portal. The issue/return/request UI remains a later development phase.

## Verification

- Production Vite build passed. PHP sources and Blade echo expressions were statically parsed; Blade block balance and JavaScript syntax were checked.
- Browser fixture checks passed for dashboard, catalog, book form and master form at 390/768/1024/1440 px. No document overflow or script errors; BN/EN inputs measured 48 px each. Multi-select, keyboard selection, preview, live search, identifier fields/match mode and filter URL updates were exercised against mocked result endpoints. Fixtures do not execute Laravel authorization or database queries.
- Equivalent SQL benchmark: 50,000 synthetic books; matching counts and first-page IDs agreed with the prior query. New general-search medians were about 5–18 ms in warm in-memory SQLite; exact identifiers were below 1 ms. Full results, including the broad-query tradeoff, are in `docs/benchmarks/catalog_50000.md`. This is not PHP/MySQL or end-to-end timing.
- Native PHP is not installed here. `php artisan test` cannot start; the full PHPUnit suite, Laravel migration execution and actual MySQL performance are unverified in this environment. No passing PHPUnit result or hardware-independent speed guarantee is claimed.
