# 0.13.1 — Report layout and loan history

11 November 2026. Apply this Paste & Replace patch over v0.13.0.

- Reports follows Catalog Setup in the main menu.
- Issue & Return, Most Issued Books, and Annual Summary distinguish loan transactions from the number of book copies on those records. The normal issue form records one copy per transaction.
- All report PDFs show the software credit at left and `Page N of M` at right.
- The requested report columns are horizontally and vertically centered in the UI, PDF and Excel.
- Member Directory shows Active and Inactive badges and totals for borrowed, returned and on-loan copies across each member's full history. The member name links to a paginated loan history with issue, due and return dates, status, and PDF/Excel downloads. Report permissions also apply to the history and downloads.
- Category Inventory shows distinct catalog title and copy totals above the table. Its footer adds the category rows across the full report. Titles assigned to multiple categories contribute to each assigned category.
- Annual Summary supports a calendar year or an inclusive custom date range. Each month counts activity within the selected dates, including partial first and last months.

Run `php artisan optimize:clear` and `php artisan test` after applying the patch.

The full suite passed with 147 tests and 5,581 assertions on PHP 8.4.27 and SQLite. Single-page and multi-page PDF footers were checked with rendered acquisitions reports.
