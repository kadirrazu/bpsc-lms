# 0.14.0 — Copy accessions, prices and PDF books

16 November 2026. Apply over the v0.13.7 reference, run `php artisan optimize:clear`, then run `php artisan migrate`. Back up the database before migrating. The migration preserves historical loan snapshots and registers the first known accession of each existing title. It cannot determine the accession numbers of the remaining physical copies. Record those numbers from the books in Edit Book. Existing legacy loans can be returned normally.

- Hard Copy is the default. Enter the first copy's accession in Accession Number. For quantities above one, paste the remaining accessions one per line. The form updates the required count and the server enforces globally unique accession numbers. Removed accessions remain reserved, and an identified copy cannot be removed while it is on loan.
- Catalog search matches additional copy accessions. When issuing, supply a specific available accession or leave the field blank to assign an available registered copy automatically. An exact available accession search on the Issue Books form preselects that accession. The issue confirmation and register show the accession assigned to the loan. Older stock with incomplete accession records retains its existing quantity-based circulation. If all numbers have been entered and an open legacy loan has no copy recorded, enter the accession on the physical copy being issued.
- Issue Requests links to live book details. Copies on Loan lists borrower, designation, unit, earliest active issue date and known copy accessions, ordered from earliest to latest.
- Purchase Price uses the existing price data in BDT. Printed Price is separate and supports BDT, USD, EUR, INR and CNY. The acquisition reports value physical copies at the recorded purchase price per copy and each soft copy at its recorded purchase price.
- Choose Soft Copy on Add Book to upload a PDF. The PDF is stored on the private Laravel disk. Signed-in Library Members download it from book details. Each served download increments the title's counter and creates a Book Activity and audit event. Soft copies do not circulate. For a 50 MB PDF, the PHP/web server upload limits must permit a request of that size.
- Existing titles keep their format. The book import template remains for hard copies and accepts the new optional columns `additional_accessions`, `printed_price` and `printed_currency`. The existing `price` column is Purchase Price in BDT.
