# 0.16.1 — Issue desk styling

24 November 2026. Apply over v0.16.0, then run:

```bash
php artisan optimize:clear
```

The member's configured limit, current loans, pending requests, and total after issue appear as four colored badges. The values update as the member and selected copies change.

The accession instructions appear in an information box. Librarians see a larger Allow Exceptional Issue switch with a highlighted explanation. The badges stack on small screens.

No migration or frontend build is required.
