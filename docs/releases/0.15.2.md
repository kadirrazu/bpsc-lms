# 0.15.2 — Issue and return receipts

17 November 2026. Apply over v0.15.1. Back up the database, run `php artisan optimize:clear`, then run `php artisan migrate`.

- Issue receipts display the member and issuer on individual lines with bold names and designations. Totals sit below the item table. Both copies have more writing space and clearer separation above the footer.
- Mark Returned offers an optional two-copy PDF for that book. Issue Requests and Issue Register also provide reprint links. The PDF lists the original issue time, return time, book, accession, quantity, and the staff member who recorded the return. Each copy has a return signature line on the right.
- New returns preserve the receiving staff member's ID, name, and designation at the time of return. Returns recorded before this update show “Not recorded” for those details.
