# Release 0.6.2 — Single-column Sign In

Baseline: v0.6.1.

- Sign In email and password fields are stacked in one column at every screen width.
- Registration keeps its responsive two-column desktop layout.
- README, database, migrations and compiled assets are unchanged.

Extract over v0.6.1, then run `php artisan optimize:clear` and `php artisan test`. No migration or rebuild is required.

Verification: responsive browser fixture checks passed for Sign In and Registration at 390, 768, 1024 and 1440 px, including footer separation. Native PHP is unavailable, so the full Laravel test suite could not run.
