# 0.16.3 — Centered book deletion dialog

26 November 2026. Apply over v0.16.2, then run:

```bash
php artisan optimize:clear
```

The book deletion dialog is explicitly positioned at the center of the viewport and opens with a short fade and slide animation. It is mounted directly under the page body. Focusing the confirmation field avoids scrolling the underlying page.

The dialog fits small screens and scrolls internally when needed. Animation is disabled when the device requests reduced motion.

No migration or frontend build is required.
