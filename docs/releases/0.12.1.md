# 0.12.1 — Optional Author and Category Dropdowns

Date: 8 November 2026. Apply over v0.12.0.

Book templates now provide Author 1–5 and Category 1–5 dropdown columns, alongside Publisher. Author 1 and Category 1 are required. **Positions 2–5 are strictly optional, accept blanks and are never prefilled.** Blank optional cells create no relations, gaps are allowed and duplicate selections are linked once. Invalid nonempty selections block the whole import. The first position is still required even when a later one is selected. Optional 2–5 headers may be omitted entirely.

Template appearance uses blue required headers, slate optional headers, subtle cell colors, readable Bengali-friendly font, larger rows, input hints and header comments. Accession and primary title are frozen while scrolling. Dropdowns display ID and name; reference sheets retain filters. Native dropdown AutoComplete depends on the user's Excel version. No VBA, macros or external add-ins are required.

More than five selections can be added through the existing searchable preview editor. v0.12.0 pipe-separated ID-list templates remain supported. Numbered and list columns for the same relation cannot be mixed in one workbook. Name-based pre-v0.12 templates remain unsupported.

## Apply

Extract the root-relative patch over v0.12.0, then run:

```sh
php artisan optimize:clear
php artisan test
```

Download a fresh Import Template to use the dropdown columns. No migration, Composer update or frontend build is required. Existing data, migrations, stable README and frontend assets remain unchanged.

## Validation

Full Laravel suite passed: **139 tests, 5,424 assertions**, native PHP 8.3.6 and SQLite in-memory. Result: `docs/validation/0.12.1-tests.json`.

Six new regression tests cover importing with only first selections, omitting optional headers, extra selections/gaps/deduplication, missing first selections, invalid optional IDs and actual XLSX save/load checks. The workbook test verifies that every optional selection cell across all 500 data rows stays empty and that dropdowns allow blanks; first-selection dropdowns remain required. Existing import tests were updated for the new template positions and still test v0.12.0 ID-list compatibility. Browser visual rendering and native Excel/WAMP/MySQL execution were not performed here.
