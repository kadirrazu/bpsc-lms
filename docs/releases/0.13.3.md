# 0.13.3 — Report totals and issue review

11 November 2026. Apply over v0.13.2 and run `php artisan optimize:clear`. This update requires no database migration.

- Annual Summary adds a bold Total row for the selected reporting period. Calendar year and date range controls sit side by side on desktop and stack on smaller screens.
- Issue & Return centers every column heading and data cell horizontally and vertically.
- Issue Books displays the member's name, designation and unit in the search results and confirmation. Email and mobile searches remain available.
- The selection and confirmation show available and issuing copies for each book. Each selection issues one copy. Availability is checked again when the issue is confirmed.
- The selection-limit message has extra spacing above it.
