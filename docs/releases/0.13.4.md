# 0.13.4 — Issue Register filters and downloads

11 November 2026. Apply over v0.13.3 and run `php artisan optimize:clear`.

- Issue Requests groups the teal Issue Register and blue Issue Book buttons together with a gap.
- Reports links to the same Issue Register used by Issue Management.
- The register filters by issue date, including both endpoints. Either date can be used on its own. The date filter combines with search, loan status and fine status.
- PDF, Excel and CSV downloads include every matching issue across all pages. PDF uses the standard BPSC header, credit and page numbering. Exports are recorded in the audit log.
