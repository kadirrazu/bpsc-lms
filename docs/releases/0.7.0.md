# Release 0.7.0 — Development Admin and XLSX Imports

Baseline: `project-reference-lms-01-11-2026-11-47-PM.zip` (v0.6.2).

## Changes

- `library:create-admin` refuses every environment except `local` / `development`, before prompting or querying the database. APP_DEBUG does not enable it. No force bypass is provided.
- Development admin creation offers all active designations and saves the selected designation; System Manager is no longer forced. The selection and unit are revalidated under a transaction lock.
- Optional Price and Collection Method (Purchase, Gift, Others) on Book Add/Edit and details, with decimal/range validation and audit coverage. Existing records remain null for both fields.
- Import XLSX beside Add on Books, Authors, Publishers and Categories. Each import page provides a downloadable, styled XLSX sample and instructions. Existing PhpSpreadsheet dependency is reused.
- New-record imports validate the whole workbook, report row errors, reject duplicates and commit atomically. Books resolve existing BN master names, support multiple authors/categories, and preserve text accession numbers. See `docs/imports.md` for columns, limits and rules.
- Access remains Administrator/Librarian/Library Staff for adding/importing catalog records. Members cannot access uploads or samples.

## Apply

Back up project/database. Extract this root-relative Paste & Replace ZIP over the baseline, then run:

```bat
php artisan optimize:clear
php artisan migrate --force
php artisan test
```

No new Composer dependency, npm install or asset rebuild is required. Existing .env, users, records and covers are preserved. README and old migrations are unchanged.

For new installations, create the initial administrator in the development environment before preparing production deployment. Later production user management uses the authorized Users interface. Development examples:

```bat
php artisan library:create-admin
```

The default `.env.example` already uses `APP_ENV=local`.

## Verification and limitations

- PHP sources and Blade echo expressions statically parsed successfully; route ordering, existing migrations, README and dependency manifests checked for unintended changes.
- Browser fixtures for import/acquisition fields passed at 390/768/1024/1440 px without horizontal overflow or console errors. Price input rejects negative/excess precision values; Collection Method selection works. These fixtures do not execute Laravel or XLSX parsing.
- Added 12 regression tests for environment guards/designation selection, imports, sample round trips/downloads, permissions, atomic errors, leading-zero accession, formulas, price and methods. Suite totals 79 tests.
- Native PHP is unavailable here: `php artisan test` cannot start (`php: command not found`). Complete PHPUnit results, native sample XLSX generation/round trips, migrations and MySQL execution remain unverified. No passing native test result is claimed.
- XLSX files with more than 500 data rows must be split; importing does not update existing records or images.
