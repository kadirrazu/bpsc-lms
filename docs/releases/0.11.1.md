# 0.11.1 — Issue Request Badges

Applies over v0.11.0. Date: 5 November 2026.

- Requested column shows a purple **Direct Issue** badge for staff-issued records and a cyan **Member Request** badge for member submissions.
- Loan activity shows a blue **On Loan** badge or neutral **Returned** badge. The status filter uses **On Loan** capitalization too.
- Request status, permissions, filtering and circulation behavior are unchanged. Stable README is unchanged.

Extract the root-relative patch into the existing project, then run `php artisan optimize:clear` and `php artisan test`. No migration or asset build is needed.

Validation: source checks verified both source badges and loan-state badges, title capitalization and unchanged baseline files. Native Laravel tests and browser rendering could not run because this environment has no PHP runtime or installed Composer dependencies. Full-suite success is not confirmed.
