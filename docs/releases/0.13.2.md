# 0.13.2 — Batch issues, renewal settings and annual summary layout

11 November 2026. Apply over v0.13.1, then run `php artisan optimize:clear` and `php artisan migrate`.

- The issue form searches active members by name, email or mobile number and available books by title, author, accession or call number. Each selected book appears in a review list. The confirmation dialog lists the member, books and loan period.
- A batch creates one loan record and issues one copy per selected catalog book. All books are issued together after validation. The member's active distinct titles plus the selection must fit the configured borrowing limit for all operators. An active loan for the same catalog book blocks another issue to that member. Request approval applies the same rules.
- Borrowing Settings adds **Maximum Renewals per Loan** (default 2, with 0 disabling renewals) and **Days per Renewal** (default 15). The initial loan period is configured separately. For overdue loans, the extension runs from the time of renewal. The register shows the number used and omits the Renew action when the limit is reached. The server validates the cap and the settings shown in the confirmation.
- Annual Summary aligns the figures across each row of cards. Table headings wrap, and narrow screens show each month with labeled values. Issue & Return, Most Issued Books and Annual Summary use a single Books Issued or Books Returned count. Historical quantities continue to contribute their recorded counts.

Verified with the full Laravel suite on PHP 8.4.27 and SQLite. A Chromium smoke test covered selecting two books, cancelling and confirming the batch, dialog button spacing, and Annual Summary card alignment and table overflow at 320, 390, 768 and 1280 pixels.
