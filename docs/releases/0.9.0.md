# Release 0.9.0 — Two-Book Policy and Fifteen-Day Loans

Baseline: v0.8.4.

- Strict member request capacity: 2 book copies including pending request slots. Request/approval/model checks prevent exceeding the active two-copy standard; returned books release capacity.
- New loans are due 15 days after their actual issue timestamp. Due dates appear in member request/loan lists, the member book notice and the management issue view. Existing loans are backfilled from their original issue date without changing their issue/return history.
- Issue Book form on the management Issue Requests page uses searchable member/book selectors. Standard circulation operators can issue within the limit. Only Librarian can exceed it, through a server-generated, expiring confirmation page that rechecks the current count, member, stock and source request before writing. Override events are audited.
- Direct issues appear as labelled management records and can be marked returned through the existing workflow.
- Users now displays Total Borrowed and On Loan quantities using aggregate queries.

See `docs/borrowing-policy.md` for exact capacity, confirmation and history semantics.

## Apply

Back up project/database, extract this root-relative patch over v0.8.4, then run:

```bat
php artisan optimize:clear
php artisan migrate --force
php artisan test
```

The migration adds due/override metadata, an active-loan index, a request source label, and backfills existing due dates in batches. Existing loans above two are retained. No Composer/npm update or asset rebuild is needed; searchable selectors reuse the existing picker script. README and old migrations remain unchanged.

## Validation

Source checks covered lock order, ownership, active/pending counting, due-date derivation, non-mass-assignable override authorization, expiring confirmation context, source labels, return behavior, aggregate user counts and template structure. Eleven borrowing-policy regression tests were added, and older large-history fixtures were revised to keep at most two active books per member. Suite totals 109 tests.

Native PHP and a local browser executable are unavailable here. `php artisan test` could not start (`php: command not found`); the full suite, native migration/backfill, concurrent MySQL behavior and authenticated UI remain unverified. No passing native suite or concurrency guarantee is claimed.
