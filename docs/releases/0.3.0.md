# Release 0.3.0 — Profile Permissions and Commission Identity

Baseline: `project-reference-31-10-2026-10-32-PM.zip` (v0.2.1).

## Changes

- Every role, including Library Member, may update its own name and sign-in email from My Profile. Designation, Unit and Role are visible as read-only values. No management fields are submitted by the form; forged profile changes to protected fields are rejected on the server.
- The Users list and all user-management endpoints are restricted to Administrator and Librarian. Users links are hidden from Staff navigation and dashboard; Staff retains its other existing library/designation permissions. Librarian's existing restrictions on higher-privilege accounts are retained.
- Profile email changes retain audit recording and session-version handling. Email verification is cleared when the sign-in email changes.
- Header commission text and login subtitle are larger and bolder in desktop and mobile layouts.
- Footer first-line text is larger; copyright is shown as `© <current year> Bangladesh Public Service Commission (BPSC). All rights reserved.` Developer credit and bold IT Section, BPSC are retained.
- Existing tests updated for the revised Staff and Member rules. Added six profile/access regression tests (24 tests in total). Root README is unchanged.

## Apply

Back up the application, then extract this Paste & Replace ZIP over the project root. Run:

```bat
php artisan optimize:clear
php artisan test
```

No migration, seeding or dependency update is required. Compiled CSS is included; rebuild only when changing frontend source.
