# 0.15.1 — Accession selection, print layouts, and account menu

17 November 2026. Apply over v0.15.0. Back up the database, run `php artisan optimize:clear`, then run `php artisan migrate`.

- Direct issue requires an explicit selection of an available accession for every book. Register physical copies in Edit Book before issuing any title whose available stock has no individual accession records.
- The membership card PDF has front and back A4 pages. The cut border on both pages measures 85.60 × 53.98 mm. Print at Actual Size (100%). For automatic duplex printing, select the long-edge flip setting. The front includes contact details, the membership number QR code, and separate librarian and member signature lines.
- Each receipt copy includes member and issuer details, signature space, the print timestamp, and the software credit. New receipts save member designation and unit and issuer details at issue time. Older receipts use the linked user records for details that were previously unsaved, when available.
- The member portal and back office share the same initials-based account menu.
