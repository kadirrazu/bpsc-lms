# 0.14.1 — Available copy selection and EPUB support

16 November 2026. Apply over v0.14.0 and run `php artisan optimize:clear`.

- Additional copy accessions use semicolon-separated input with whitespace trimmed. Older newline-separated input is still accepted for paste and import. The form blocks adding more numbers than the copy count allows.
- Direct issue and member request approval can search and select registered, available copy accessions. The issue transaction rechecks the selected copy before recording it. Available legacy stock without a registered accession can still be issued through the existing legacy workflow.
- Selected books show serial number, title and authors. Copy accession selection appears below each book.
- Book format appears above Cover Image. Soft copies require a PDF or EPUB file when created. The upload is below Cover Image and accepts a file of up to 50 MB. Signed-in members download the original file format with download counts and audit events.
