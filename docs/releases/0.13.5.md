# 0.13.5 — Issue Register sorting

11 November 2026. Apply over v0.13.4 and run `php artisan optimize:clear`.

- Issue Register keeps the latest saved records first by default. The **Sort by** filter also offers oldest first and newest first by issue date and time.
- Pagination and PDF, Excel and CSV downloads follow the selected order. The CSV default now matches the register. Records with the same issue timestamp use their record ID to keep the order consistent.
